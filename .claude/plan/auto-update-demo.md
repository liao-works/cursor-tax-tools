# 自动更新功能演示

## 功能介绍

自动更新功能允许用户一键自动抓取最新税率数据，并与当前数据库中的数据进行智能对比，只在有实际变化时才更新数据。

## 核心特性

1. **智能对比**
   - 自动抓取英国税率网页内容
   - 解析最新税率信息
   - 智能对比当前数据（忽略大小写和空格差异）
   - 只在有变化时更新

2. **异步处理**
   - 后台线程执行抓取，避免UI阻塞
   - 实时状态反馈
   - 错误处理和重试机制

3. **用户体验**
   - 确认对话框防止误操作
   - 详细的成功/失败反馈
   - 显示变化前后的对比信息

## 使用场景

### 场景1：定期更新税率
```
用户查询了某个商品编码，发现税率可能已经更新
→ 右键点击结果行
→ 选择"自动更新"
→ 确认操作
→ 程序自动抓取最新税率并对比
→ 如果有变化则更新并显示详情
```

### 场景2：批量更新多个商品
```
用户需要更新多个商品的税率
→ 逐个搜索商品编码
→ 对每个结果执行"自动更新"
→ 程序自动处理每个商品的更新
```

## 技本实现

### 1. 网页抓取
- 使用tools.web_scraper模块异步抓取
- 设置合理的请求头模拟浏览器
- 支持超时和重试机制

### 2. 内容解析
- 使用BeautifulSoup解析HTML
- 查找税率表格结构
- 提取"All countries"或"United Kingdom"的税率

### 3. 数据对比
```python
# 智能对比逻辑
old_rate = old_data.get('rate', '') or ''
new_rate_clean = new_rate.strip().lower() if new_rate else ''
old_rate_clean = old_rate.strip().lower() if old_rate else ''

rate_changed = new_rate_clean != old_rate_clean
```

### 4. 更新策略
- 部分字段更新（只更新变化的字段）
- 事务性操作保证数据一致性
- 详细的日志记录

## 返回结果格式

```python
{
    'success': True,        # 操作是否成功
    'message': str,         # 结果描述信息
    'updated': True,        # 是否实际更新了数据
    'old_data': {...},      # 更新前的数据
    'new_data': {...}       # 更新后的数据
}
```

## 注意事项

1. **网络依赖**
   - 需要稳定的网络连接
   - 如果网站结构变化可能需要更新解析逻辑

2. **频率控制**
   - 建议不要过于频繁地执行自动更新
   - 每次更新之间间隔1-2秒

3. **数据验证**
   - 抓取的数据会与现有数据进行对比
   - 不会盲目覆盖现有数据

4. **错误处理**
   - 网络错误、解析错误等都有相应处理
   - 不会影响其他功能的正常使用
