# 双地区税率自动更新功能

## 功能概述

扩展了自动更新功能，现在可以同时更新英国和北爱尔兰的税率信息。

## 功能特性

### 1. 同时支持两个地区
- **英国税率**：自动抓取并更新英国税率
- **北爱尔兰税率**：自动抓取并更新北爱尔兰税率
- **智能对比**：分别对比两个地区的税率变化
- **部分更新**：仅更新有变化的地区

### 2. 灵活的使用方式
- **双地区更新**：同时传递英国和北爱尔兰URL（推荐）
- **单地区更新**：只传递英国URL，北爱尔兰URL为None
- **智能识别**：自动检测URL是否存在

### 3. 详细的状态反馈
- 显示两个地区的税率变化
- 明确指出哪些地区有更新
- 提供变化前后的对比信息

## 技术实现

### 架构设计

```
tariff_gui.py (GUI层)
    ↓ 传递两个URL
tariff_api.py (API层)
    ↓ 委托执行
scraper.py (抓取层)
    ├─ 抓取英国页面 → 解析英国税率
    └─ 抓取北爱尔兰页面 → 解析北爱尔兰税率
    ↓ 对比并更新
tariff_db.py (数据库层)
```

### 修改的文件

#### 1. scraper.py
**新增功能：**
- `auto_update_single()` 方法支持双URL参数
- 分别抓取两个地区的页面
- 分别解析两个地区的税率
- 智能对比并更新

**方法签名：**
```python
def auto_update_single(self, code: str, uk_url: str, ni_url: str = None) -> Dict
```

**处理流程：**
1. 获取当前数据
2. 抓取英国页面并解析税率
3. 抓取北爱尔兰页面并解析税率（如果URL存在）
4. 对比英国税率变化
5. 对比北爱尔兰税率变化
6. 对比描述变化
7. 执行更新（只更新变化的字段）
8. 返回详细结果

#### 2. tariff_api.py
**修改内容：**
- `auto_update()` 方法支持双URL参数
- 直接委托给 `TariffScraper.auto_update_single()`

**方法签名：**
```python
def auto_update(self, code: str, uk_url: str, ni_url: str = None) -> Dict
```

#### 3. tariff_gui.py
**修改内容：**
- `auto_update()` 方法获取北爱尔兰URL
- ` _do_auto_update()` 方法传递两个URL
- `_handle_auto_update_result()` 方法显示双地区对比信息

**GUI交互：**
- 自动获取表格中的北爱尔兰URL
- 确认对话框显示更新范围
- 结果对话框显示两个地区的税率对比

## 使用方法

### 步骤1：搜索数据
在搜索框输入商品编码并搜索

### 步骤2：选择记录
在搜索结果表格中选中要更新的记录

### 步骤3：右键菜单
右键点击选中的记录

### 步骤4：选择自动更新
从右键菜单选择"自动更新"

### 步骤5：确认操作
在确认对话框中点击"是"

### 步骤6：查看结果
程序自动抓取并更新数据，显示更新结果

## 更新范围

根据记录的URL情况，更新范围会有所不同：

### 情况1：有北爱尔兰URL
```
更新范围：英国税率和北爱尔兰税率
确认消息：将自动抓取商品编码 {code} 的最新税率数据（英国税率和北爱尔兰税率）并与当前数据对比，如有变化则更新。
```

### 情况2：无北爱尔兰URL
```
更新范围：仅英国税率
确认消息：将自动抓取商品编码 {code} 的最新税率数据（英国税率）并与当前数据对比，如有变化则更新。
```

## 结果显示

### 成功更新时
显示详细信息对话框：
```
商品编码: {code}

原英国税率: {old_uk_rate}
新英国税率: {new_uk_rate}

原北爱尔兰税率: {old_ni_rate}
新北爱尔兰税率: {new_ni_rate}

成功更新数据（英国税率、北爱尔兰税率）
```

### 无变化时
显示简洁消息：
```
英国税率、北爱尔兰税率和描述均无变化，无需更新
```

## URL格式

### 英国URL
```
https://www.trade-tariff.service.gov.uk/commodities/{code}
```

### 北爱尔兰URL
```
https://www.trade-tariff.service.gov.uk/xi/commodities//{code}
```

注意：北爱尔兰URL中有一个额外的斜杠。

## 错误处理

### 网络错误
- 抓取失败时显示错误消息
- 不影响其他功能的正常使用

### 解析错误
- 解析失败时返回错误信息
- 不会更新数据库

### URL不存在
- 如果英国URL不存在，无法执行更新
- 如果北爱尔兰URL不存在，仅更新英国税率

- ✅ 错误恢复：单个地区的错误不影响另一个地区
