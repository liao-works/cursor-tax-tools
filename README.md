# 英国海关编码税率查询工具

一个用于快速查询英国海关编码税率的桌面应用程序。本工具支持精确查询和模糊匹配，可以帮助用户快速找到相关商品的海关编码和税率信息。

## 功能特点

- 🔍 **精确查询**：通过完整的商品编码进行精确查询
- 🌐 **模糊匹配**：支持模糊搜索，帮助用户找到相似编码
- 📊 **批量处理**：支持通过 Excel 文件批量查询税率
- 💾 **离线使用**：所有数据本地存储，无需联网
- 🔄 **智能更新**：自动检测并下载最新税率数据
- 📋 **复制功能**：快速复制查询结果
- 🎯 **单条更新**：支持右键菜单自动更新单个商品税率

## 使用说明

### 首次使用

1. 下载并解压最新版本的程序
2. 运行 `uk-tax-tools.exe`
3. 切换到"远程数据更新"标签页
4. 点击"🔍 检查更新"下载最新税率数据库
5. 等待下载完成后即可开始查询

### 单个查询

1. 切换到"单个查询"标签页
2. 在搜索框中输入商品编码
3. 选择查询模式（精确/模糊）
4. 点击查询按钮获取结果
5. 右键点击结果可以复制税率或自动更新数据

### 批量查询

1. 切换到"批量查询"标签页
2. 点击"下载模板"获取 Excel 模板文件
3. 在模板中填入需要查询的商品编码
4. 点击"选择文件"上传填写好的 Excel 文件
5. 等待处理完成后下载结果

### 数据更新

1. 切换到"远程数据更新"标签页
2. 点击"🔍 检查更新"查看是否有新版本
3. 如有更新，会弹出确认对话框显示详细信息
4. 点击"是"开始下载并自动更新数据库
5. 也可以点击"🔄 强制更新"直接下载最新版本

## 系统要求

- Windows 7 及以上操作系统
- 不需要安装 Python 或其他依赖
- 至少 200MB 可用磁盘空间（用于存储数据库和更新文件）
- 需要网络连接以下载和更新税率数据

## 目录结构

解压后的程序目录结构如下：

```
uk-tax-tools/
├── uk-tax-tools.exe          # 主程序
├── templates/                 # Excel 模板文件夹
│   └── template.xlsx         # 批量查询模板
└── datas/                    # 数据文件夹（首次运行后自动创建）
    ├── tariffs.db            # 税率数据库
    └── tariffs.db.metadata.json  # 数据库元数据
```
